Cricket Rivals: Design Concept & Architecture

Detailed specification and structural overview

1. Project Overview

Cricket Rivals is a high-energy, competitive multiplayer cricket gaming platform designed with a modern, "light mode" aesthetic. The platform focuses on fast-paced 12v12 matches, custom room creation, and a challenging "Play vs Bot" mode, all unified by a clean light green and white visual identity.

2. Visual Identity & Design System

  • Core Palette: Primary "Cricket Green" (#2bee2b), Crisp White backgrounds, and Dark Navy typography.
  • Typography: Space Grotesk throughout for a technical and sporty feel.
  • Shape Language: Standard 8px corner radius for consistency across all components.
  • Iconography: Custom minimalist icons replace emojis for a professional gaming aesthetic.

3. Core Architecture

The application uses a Unified Global Header for desktop and a Context-Aware Bottom Bar for mobile to ensure a seamless "connected" feel across all views.

  • Dashboard: Central hub for player stats and game modes.
  • Global Leaderboard: Top 10 rankings with personal progress tracking.
  • User Profile: Detailed lifetime stats and match history.

4. Key User Flows

Competitive Matchmaking (12v12)

A multi-stage flow: Queueing -> Lobby (Chat & Sync) -> Strategy (Captain Setup) -> Live Gameplay -> Post-Match Analysis.

Custom Rooms & Bot Play

Flexible options for social play (Room IDs) and solo training (Difficulty-based Bot matches).

5. Mobile Strategy

Optimized for vertical play, the mobile version reduces visual clutter in lobbies and prioritizes thumb-friendly interaction areas in the game interface, ensuring high performance on any device.
